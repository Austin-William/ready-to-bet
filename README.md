# Ready To Bet

A friendly bet tracker built with React, TypeScript, and Vite.

## Run locally

```sh
npm ci
npm run dev
```

## Deploy to GitHub Pages

The workflow in `.github/workflows/deploy-pages.yml` builds and deploys the app whenever code is pushed to `main`. It can also be started manually from the repository’s **Actions** tab.

In the repository settings, open **Pages** and set the publishing source to **GitHub Actions**. The published site will be available at:

<https://austin-william.github.io/ready-to-bet/>
